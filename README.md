## 📋 Overview

ProMechDirectory is a full-stack B2B marketplace platform that connects engineering service providers with customers seeking specialized engineering services.

### Key Features

- 🔍 **AI-Powered Search** - Natural language search with vector embeddings
- 📋 **RFQ Management** - Request for Quote workflow with provider matching
- 💳 **Payment Processing** - Stripe integration for subscriptions and transactions
- 📄 **NDA Handling** - Digital document signing integration
- 📝 **Provider Profiles** - Rich profiles with AI embeddings
- 🎯 **Advertising System** - Featured listings and ad placements
- 👨‍💼 **Admin Dashboard** - Complete back-office management

## 🚀 Quick Start

### Deploy to Render (Recommended)

1. **Fork this repository** to your GitHub account
2. **Go to [Render Dashboard](https://dashboard.render.com/blueprints)**
3. Click **"New Blueprint Instance"**
4. Connect your GitHub account and select this repository
5. Render will automatically create all services from `render.yaml`

### Environment Variables

Required environment variables for production:

| Variable | Purpose | Get From |
|----------|---------|----------|
| `SECRET_KEY` | JWT signing | Auto-generated by Render |
| `DATABASE_URL` | PostgreSQL connection | Auto-generated by Render |
| `REDIS_URL` | Redis connection | Auto-generated by Render |
| `OPENAI_API_KEY` | AI embeddings | [OpenAI](https://platform.openai.com) |
| `STRIPE_SECRET_KEY` | Payment processing | [Stripe](https://dashboard.stripe.com) |
| `STRIPE_PUBLISHABLE_KEY` | Frontend payments | [Stripe](https://dashboard.stripe.com) |
| `RESEND_API_KEY` | Email sending | [Resend](https://resend.com) |

See `.env.example` for complete list.

## 🛠️ Tech Stack

### Backend
- **FastAPI** - Modern Python web framework
- **SQLAlchemy** - ORM for database operations
- **PostgreSQL** - Primary database with pgvector extension
- **Redis** - Caching and Celery broker
- **Celery** - Background task processing
- **OpenAI** - Embeddings and AI features
- **Stripe** - Payment processing

### Frontend
- **Next.js 15** - React framework with App Router
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **shadcn/ui** - UI component library
