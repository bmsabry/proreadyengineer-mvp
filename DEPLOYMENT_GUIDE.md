## 🔧 Post-Deployment Configuration

### Set Up Stripe Webhooks

1. Go to Stripe Dashboard → Developers → Webhooks
2. Add endpoint: `https://proreadyengineer-api.onrender.com/webhooks/stripe`
3. Select events:
   - `payment_intent.succeeded`
   - `invoice.paid`
   - `customer.subscription.deleted`
4. Copy webhook secret to Render env vars

### Set Up Resend Domain

1. Go to Resend Dashboard
2. Add and verify your domain
3. Update `EMAIL_FROM` in Render env vars

## 📞 Troubleshooting

### Database connection issues
- Check `DATABASE_URL` is set correctly
- Verify database is "Available" in Render dashboard

### CORS errors
- Ensure `FRONTEND_URL` matches your actual frontend URL
- Check `ALLOWED_ORIGINS` includes your domain

### API not responding
- Check logs in Render dashboard
- Verify health check endpoint: `/health`
